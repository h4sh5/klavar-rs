Clean-room re-implementation of the Klavar notation converter in Rust → WebAssembly. The klavar staff runs vertically: pitch across, time down, filled noteheads on black-key lines, hollow noteheads between them. Horizontal stems: → right hand, ← left hand · ◦ release · dots mark notes held over a bar line.
